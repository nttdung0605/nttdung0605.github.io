### Thành quả của tuần 5:

* Thành công tạo endpoint API Gateway và tích hợp với Lambda để expose chức năng serverless ra internet.

* Học cách cấu hình API Gateway để định tuyến request tới Lambda và bật cơ bản API access.

* Có kinh nghiệm thực tế với cấu hình CORS để cho phép web client gọi API một cách an toàn.

* Hoàn thành workshop serverless liên quan đến Lambda, S3 và DynamoDB, củng cố hiểu biết về kiến trúc serverless end-to-end.

* Mở rộng hiểu biết về cách frontend và backend có thể giao tiếp qua API Gateway trong một ứng dụng serverless.
