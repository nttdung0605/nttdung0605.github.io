After completing this workshop, to avoid any unexpected charges, delete the REST API in API Gateway, the two Lambda functions, the DynamoDB table, and the IAM Role and Policy to keep the environment clean.

#### Delete API Gateway
* Open API Gatewyat, choose api and delete.
![Picture](/images/5-Workshop/5.8/5-8-1.png) 

#### Delete Lambda Functions
* Open Lambda, choose funtions and delete.
![Picture](/images/5-Workshop/5.8/5-8-2.png) 

#### Delete DynamoDB Table
* Open DynamoDB, choose table and delete.
![Picture](/images/5-Workshop/5.8/5-8-3.png) 

#### Delete IAM Role and IAM Policy
* Open IAM, choose role and delete.
![Picture](/images/5-Workshop/5.8/5-8-4.png) 
* Go to Policy tab and delete.
![Picture](/images/5-Workshop/5.8/5-8-5.png)
