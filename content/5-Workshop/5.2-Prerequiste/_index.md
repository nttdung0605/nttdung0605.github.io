* **AWS Account** An active AWS Account is required. It is highly recommended to use an IAM User with **AdministratorAccess** privileges rather than the root account for better security practices.

* **API Testing Tool**: Install Postman to simulate client requests and test the API endpoints.

* **Development Environment**: A basic text editor is sufficient, as the business logic (Node.js) will be written directly within the AWS Lambda Console.
